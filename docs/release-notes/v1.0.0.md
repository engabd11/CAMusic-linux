The first standalone release of **CAMusic for Linux**: the always-on touchscreen panel for a bit-perfect stereo. MPD plays (straight to the DAC), Jellyfin is the library, and HueGhost follows the session to your Hue lights.

## Highlights

**Now playing, made for a panel that never turns off**
- **Steady album art.** The cover is held for the whole album, so skipping tracks no longer flashes the art, the backdrop or the colours.
- **Album change.** When a new album starts the cover turns over like a sleeve in the hand (or dissolves, or slides; your choice) and the room's colours turn with it.
- **Living cover.** About 10 s into each track the cover comes quietly alive: water, sky and smoke seem to drift, light plays on the highlights and the print breathes. Lettering and sharp lines stay still. Pausing settles it. Off / Subtle / Vivid.
- Titles glide on track changes, the colour blooms drift slowly, the controls respond to the touch, and the cover rests back while paused.

**Listening mode (new).** When music plays and nobody touches the panel for a few minutes, the controls step aside and the record takes the screen: a large living cover, the title set in a typeface chosen for the record, a thin progress line, the signal path (e.g. `FLAC 24/96 → DX5 II`) and a clock. A tap brings the controls back.

**Screensaver.** When nothing plays, your album covers take the screen: gallery wall, album colours or full-bleed styles, with a clock, hold-to-play and burn-in drift.

**Library.** Browse and search Jellyfin by album, artist, playlist and genre, and queue to MPD. Tapping **Library** again returns to the library home page. Pages slide and tabs cross-fade.

**Lights and settings.** HueGhost sync on/off, mode, intensity and offset; ReplayGain (off / track / album) applied by MPD. Every look and motion option above can be turned off in Settings.

Both are built for **Linux x86_64**.

## Install

```bash
tar -xzf CAMusic-linux-1.0.0-x86_64.tar.gz
cd CAMusic-linux-1.0.0-x86_64
sudo ./install.sh            # → /opt/camusic-linux, a menu entry, and the `camusic` command
camusic
```

Or run it in place without installing: `./CAMusic/bin/CAMusic`. Remove with `sudo ./install.sh --remove`. Your settings in `~/.config/camusic/settings.json` are kept either way.

On first start, open **Settings → Connections** and enter your MPD address, Jellyfin URL and API key, the Jellyfin → MPD path prefix, and (optionally) HueGhost. The README explains each setting.

## Notes

- This is the first release since the panel was separated from the original Android CAMusic app. The Android app continues in its own repository.
- The new visuals (album transitions, living cover, Listening mode) passed the unit tests and render in the CI previews. The first runs on real panel hardware will be their real test; every one of them can be switched off in **Settings → Now playing & motion** if anything misbehaves.
