## Fixed

- **Stop and Start on the Lights page reach HueGhost.** The panel sent them to the wrong address (`/apioff` instead of `/api/off`), HueGhost answered "unknown path", and the panel said nothing, so the button looked as if it did nothing at all. Mode, intensity and timing were never affected. If HueGhost ever refuses Stop or Start, the page now says so for a few seconds instead of staying silent.
