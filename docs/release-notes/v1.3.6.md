**Stop means stop.** A fix for the Lights page.

## Fixed

- **The Stop button stops the light sync.** Start and Stop were decided by whether the lights were moving at that moment. Between songs, or while HueGhost waits for the music, they are still while sync is switched on, and a press on Stop could read that stillness and send Start instead, so sync carried on. The button now follows whether sync is switched on, and does what it showed: Stop always stops, Start always starts.

## Changed

- **The Lights page says when sync is on but waiting**: "Waiting for the music", with the button still on Stop, instead of calling it idle.
