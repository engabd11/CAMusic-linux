## Fixed

- **Play, pause and Track gain answer every tap on Now Playing.** A finger that rolled a pixel or two while tapping was taken as the start of a swipe-down: the page dipped a little and the button did nothing. A drag now starts only once the finger has moved about 12 dp, so a tap stays a tap. Swiping the page down, swiping up for the queue, and scrolling lists work as before.
